## 1. 一句话

你在废弃设施里清怪撤离：短局俯视幸存者，打怪升级捡枪械与奇怪道具，章节推进 + 装备养成 + IAA。

正式名：**怪奇撤离**（包内文件夹可暂仍为 glow-survivor，对外标题全改）。

---

## 2. 画风规范（必须统一）

| 项 | 规定 |
|---|---|
| 透视 | 俯视略 2.5D（与现引擎一致，**不改视角代码大结构**） |
| 角色/怪 | 粗描边、大头小身、夸张五官，参考图那种「神经质笑脸」质感 |
| 场景 | 米色地毯/瓷砖、子弹孔墙、碎椅、纸张、灯管；三套：办公区 / 病房走廊 / 地下机房 |
| 色调 | 灰褐、米、青绿怪物点缀；UI 深半透明条 + 红/黄警示字 |
| 图标 | AI 统一粗描边物品图，禁止 emoji、禁止梦幻金框精灵风 |

## 4. 武器 / 道具（逻辑自洽：人类废墟装备）

局内三选一示例：
- 穿透弹匣、散射弹、弹射跳弹  
- 工业风扇刃、灭火器喷射、订书钉风暴  
- 医疗针回血、肾上腺素移速  
- 遥控扫地机（环绕自动打）  
- 催泪罐减速、地刺夹子  
- 激光笔致盲（短射线，科工残件，合理）  
禁止：孢子瓜魔法、萤火精灵环、露珠咒术等奇幻名。

## 5. 怪物

普通：绿皮丧尸、爬行患者、保安机器人残骸、阴影潜伏者  
精英：带预警冲撞的铠甲尸、落雷故障灯、分裂孢袋（生化罐）、反弹护盾机  
Boss：办公区「黏液主管」、病房「巡夜医师」、机房「灯笼发电机魔改」— 名称偏荒诞卡通，技能有地面预警
