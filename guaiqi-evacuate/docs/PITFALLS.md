# 踩过的坑（务必读）

## 画风来回扯

| 现象 | 原因 | 结论 |
|------|------|------|
| 边缘「毛躁」 | 细锯齿边 + 双线性放大 / 半透明脏边 | 要干净外轮廓；最终用**平滑粗边** |
| 「像素风弄没了」 | 做成柔边插画或过度抗锯齿填平 | 保留**轻微**像素感 |
| 「太像素了风格全错」 | lo-res 硬像素母版 + 硬锯齿描边 | **禁止**硬块状像素方案 |
| 描边中间一圈白 | 描边按平滑膨胀轮廓画，与实体 alpha 之间有透明缝 | 只填透明缝为黑；**禁止**把浅色填充涂黑 |
| 里面被涂黑 | 「吃掉靠近描边的浅色像素」过激 | 填充永远叠在描边之上；禁止侵蚀内部颜色 |
| 未自审就发给用户 | 急于交付 | **出图前自审**：内部色、白缝、方向 |

## 渲染

- `imageSmoothingEnabled = false` + 硬像素边 → 放大更毛；现行平滑描边配合 **smoothing on**
- CSS `image-rendering: pixelated` 与平滑描边冲突 → 战斗画布用 `auto`
- HiDPI / `VIEW_ZOOM` 会放大瑕疵 → 描边与接缝要在最终屏幕尺寸下验

## 战斗表现

- 镜头抖动、走路扭摆 → 用户明确讨厌，已关
- 角色贴图被强行压成错误宽高比 → 用真实 aspect 绘制
- 装饰家具与可拾取道具难区分 → 战斗场景不放装饰家具
- 物资箱侧面/过小 → 改正面、放大、脉冲标识

## 流程

- 美术 bot 与程序后处理方向不一致时，以**用户最新一句话**为准，并立刻纠偏队友
- Cloud Agent 推 Pages：合并后核对线上文件 hash；强刷才能看到新图

## 2026-10-19 补充

- 角色半写实被用户否决 → 必须 Style D 扁平潮玩；不要再生成真人感立绘。
