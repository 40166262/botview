# TapTap 图片尺寸（占位）

给《怪奇撤离》详情页备料。数字抄自 2026-10-19 公开文档 [游戏物料要求](https://developer.taptap.cn/docs/store/release/publish/material/)。提交前打开开发者中心再对一次，以当天表单为准。小游戏若走另一套宣发物料表，也要单独对。

本目录的 PNG 是实机截图，不是图标或宣传图。

## 还要准备的图

| 物料 | 尺寸 | 格式与体积 | 状态 |
| --- | --- | --- | --- |
| 图标（必填） | 不低于 512×512，1:1，直角方图 | png/jpg。不要圆角、不要透明底、纯白底或纯黑底 | 缺。`assets/logo_evacuate.png` 为 384×314，不能直接上传 |
| 游戏截图（必填） | 竖版不低于 720×1280；横版不低于 1280×720。全套同一方向 | png/jpg，至少 3 张，单张 ≤ 4 MB | 已有竖图，见上表 |
| 宣传图 16:9（必填） | 不低于 1920×1080 | png/jpg，≤ 4 MB。图上要有清晰游戏名，除此之外不要别的字；不要图标，不要截图拼贴 | 缺 |
| 宣传图 1:1 | 不低于 1440×1440 | png/jpg，≤ 4 MB。主体与 16:9 一致。上传竖版实机录屏时必填 | 缺 |
| 实机录屏（下载/试玩必填） | 短边 ≥ 540 px，宽高比 21:9 到 9:21。竖版建议 720×1280 或以上 | mp4/mov，H.264 或 HEVC，> 15 秒，建议 2 分钟内，≤ 5 GB | 缺。前 5 秒要进核心玩法，不要只放抽奖 |
| 游戏 LOGO | 宽 1280 px 或高 720 px 其一即可 | png，≤ 4 MB，多余区域透明 | 缺 |
| 横版封面 | 460×215 | png/jpg，≤ 3 MB。要有 LOGO 和游戏名 | 缺 |
| 竖版封面 | 600×900 | png/jpg，≤ 3 MB。要有 LOGO 和游戏名 | 缺 |
| 游戏库背景壁纸 | 3840×1240 | png/jpg，≤ 10 MB。不要 LOGO 和任何字 | 缺 |

宣传图和封面只放游戏名（封面可再加 LOGO），不要再写「免费」「无内购」等宣传句。那些话放简介。
