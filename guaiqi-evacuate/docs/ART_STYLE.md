# 《怪奇撤离》画风定稿（2026-10-19）

## 一句话（现行）

**角色：扁平潮玩（Style D / flat pop chibi）全身正面立绘 + 平滑粗黑描边。**  
**敌人 / UI 图标：轻微像素填充 + 平滑粗黑描边（贴合、不吃内部色、不透白缝）。**  
明亮可爱；米色 + 暖橙 + 青绿 UI；非写实、非泥灰恐怖。

## 角色（用户 2026-10-19 选定）

用户在多套风格样张中选定 **D：扁平潮玩**，并整批换上六人：

| mecha → medic | 星铠机甲 | 机甲 |

要求：卡通 / 动画游戏风统一全身；**不要**半写实 / 真人感；金星母题可保留；RGBA 透明底；高约 480。

## 必须遵守

| 项 | 规定 |
|----|------|
| 角色填充 | 扁平潮玩：干净色块、Q 比例、潮玩饰品感 |
| 敌人填充 | 「轻微像素」：一点复古块面，**不要**硬台阶 lo-res |
| 外轮廓 | **平滑粗黑边**：抗锯齿、干净；贴紧轮廓，**无白缝/透底**；不吃内部色 |
| 朝向 | 人物与怪物统一**正面**全身；左右走**不翻转** |
| 色板 | UI：米色 / 奶油、暖橙、青绿点缀；明亮不发黑发灰 |
| 战斗融合 | 人物、怪物、地板描边饱和度明暗尽量一致，避免贴纸感 |
| 战斗背景 | **不要**床、桌子等装饰；只留可交互物资箱/道具 |
| 运动 | **不要**镜头抖动；走动**不要**扭摆/挤压 |
| 图标 | 禁用 emoji；统一 AI/处理风格；升级表 `upgrade_icons_sheet` 5×5 |
| 击杀特效 | 不要太闪（护眼） |
| 出图 | **自审通过再发用户** |

## 明确否决

1. 半写实 / 真人感角色立绘  
2. 硬块状像素 / lo-res 硬台阶  
3. 描边吃内部色、描边白缝  
4. 半身立绘、抠透明出错、霓虹赛博、emoji 图标  
5. 战斗装饰家具、镜头抖动、走路扭摆  

## 技术落地

- 角色：美术裁切 RGBA（`836acc7`）；逻辑 id 仍为 grin/medic/…  
- 敌人：轻微像素 + 代码/美术平滑粗边（PR#24 一脉）  
- Canvas：`imageSmoothingEnabled = true`；`#game { image-rendering: auto }`  
- 镜头抖动 / 走路扭摆：已关
