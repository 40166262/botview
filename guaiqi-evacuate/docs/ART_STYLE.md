# 《怪奇撤离》画风定稿（2026-10-18）

## 一句话（现行）

**轻微像素填充 + 平滑粗黑描边（贴合、不吃内部色、不透白缝）。**  
明亮可爱、米色 + 暖橙 + 青绿；正面全身立绘；非写实、非泥灰恐怖。

## 必须遵守

| 项 | 规定 |
|----|------|
| 填充 | 「轻微像素」：有一点复古块面感，但**不要**大色块硬台阶 / lo-res 母版最近邻放大那种「太像素」 |
| 外轮廓 | **平滑粗黑边**：抗锯齿、干净；描边贴紧人物，**中间不能有白缝/透底** |
| 朝向 | 人物与怪物统一**正面**全身立绘；左右走**不翻转**、不做方向区分 |
| 色板 | 米色 / 奶油、暖橙、青绿 / 墨绿点缀；明亮不发黑发灰 |
| 战斗融合 | 人物、怪物、地板描边饱和度明暗一致，不能像贴纸各画各的 |
| 战斗背景 | **不要**床、桌子等装饰摆设；只留可交互物资箱/道具，背景干净 |
| 运动 | **不要**镜头抖动；走动**不要**扭摆/挤压变形 |
| 图标 | 禁用 emoji；统一 AI/处理风格；升级表 `upgrade_icons_sheet` 5×5 |
| 击杀特效 | 不要太闪（护眼） |

## 明确否决（不要再做）

1. **硬块状像素 / lo-res 像素格母版**（用户：「太像素了、风格全错了」）
2. **只在软边上程序加粗、内部仍柔糊且外圈毛躁**
3. **平滑插画到完全看不出轻微像素**（用户也曾说「像素风弄没了」——取中间态）
4. **描边吃掉内部颜色**（白外套被涂黑等）
5. **描边与人之间白圈/透底**
6. 半身立绘、抠图透明出错、霓虹赛博、emoji 图标

## 技术落地（现行 PR#24）

- 原图：轻微像素立绘（`art_new/v9` 一脉）
- 后处理：代码加平滑粗描边（轮廓贴合、填充保留）
- Canvas：`imageSmoothingEnabled = true`；`#game { image-rendering: auto }`
- 镜头抖动 / 走路扭摆：已关闭（PR#22）

## 历史别名

曾称「Style E 明亮块状像素」；后经用户纠正为「轻微像素 + 平滑粗边」。文档里若仍见 Style E，按本页现行解释执行。
